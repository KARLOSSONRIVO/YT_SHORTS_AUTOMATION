# FLUX.2 Klein 4B Scene Image Generation Design

## Goal

Replace the default Cloudflare Workers AI scene-image model with
`@cf/black-forest-labs/flux-2-klein-4b` without breaking the existing vertical
faceless-video pipeline or the legacy Stable Diffusion request path.

## API compatibility

FLUX.2 Klein 4B requires `multipart/form-data`, including for prompt-only image
generation. The Cloudflare client will select the request encoding from the
model identifier:

- FLUX.2 Klein receives multipart fields for `prompt`, `width`, `height`, and
  `guidance`.
- Existing Cloudflare image models continue to receive the current JSON payload.
- The client continues accepting binary image responses and Cloudflare JSON
  envelopes containing a base64-encoded `result.image`.

Klein uses a fixed four-step inference process, so the request will not send
`num_steps`. Because Klein does not expose `negative_prompt`, any negative
instructions will be appended to the main prompt as an explicit avoidance
sentence.

## Configuration

The application default, runtime `.env`, documentation example, and provider
routing expectations will use `@cf/black-forest-labs/flux-2-klein-4b`.
Generated scenes remain vertical at 1024 by 1792 pixels, within the model's
supported dimensions.

## Failure handling

Existing behavior remains unchanged for network errors, Cloudflare HTTP errors,
429 rate limits, empty output, invalid JSON, and invalid base64 image data. The
multipart boundary will be generated by the HTTP client rather than being set
manually.

## Verification

Tests will prove that Klein requests:

1. target the selected model endpoint;
2. use multipart encoding and contain the required vertical dimensions;
3. omit `num_steps` and the unsupported `negative_prompt` field;
4. preserve avoidance instructions inside the prompt;
5. decode Cloudflare's base64 image response;
6. become the configuration and dependency-injection default.

After the focused tests, the full Python test suite will run. The Python worker
will then be rebuilt and restarted, followed by one live image-generation smoke
test using the configured model.

## Security follow-up

The Cloudflare API token must be rotated because it appeared in terminal output
during configuration inspection. The replacement token must be stored only in
the local `.env` file and must not be committed.
